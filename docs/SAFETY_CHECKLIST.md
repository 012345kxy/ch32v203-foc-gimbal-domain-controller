# 安全检查清单

本项目面向云台和机器人姿态控制，测试时请优先保证机械结构和供电安全。

## 上电前

- 检查输入电源极性、3.3V/5V 电源轨、USB 串口和 CAN 收发器供电。
- 确认 IMU、地磁仪和主控周边没有短路或虚焊。
- 初次上电使用限流电源，不直接连接高功率云台或执行器。
- 外部云台驱动器接入前先确认通信线序、地线和电平兼容。

## 调试中

- 机械云台测试前固定载荷，避免失控摆动。
- 切换控制模式或通信协议时，先降低执行器力矩或速度限制。
- CAN 总线异常、姿态数据跳变或电源不稳时立即停止运动测试。
- 地磁仪调试应远离大电流线缆、磁铁和电机干扰源。

## 发布前

- 在 README 或 Issue 中公开已验证的供电范围、通信方式和传感器状态。
- 未验证的控制精度或稳定性不要写成承诺值。
- 与机械安全相关的缺陷应优先修复或明确标注为已知问题。
